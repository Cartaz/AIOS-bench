# Durable Workflow Preferences

These are lasting guidelines about how to work. They apply to all future sessions and tasks.

## Preferences

1. **Python for small automation tools** — Prefer Python when building small automation tools and scripts.
2. **Simple maintainable tools** — Always write simple, maintainable code and tools. Prioritize clarity and readability over cleverness.
3. **Never create a Git commit without explicit approval** — Do not run `git commit` (or any commit operation) unless the user explicitly asks for or approves it.

## Notes

- These preferences are durable and should persist across sessions.
- Temporary instructions (specific, one-off task requests) should NOT be stored here.
- Only general, lasting guidelines belong in this file.
